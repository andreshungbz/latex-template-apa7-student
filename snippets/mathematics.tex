\subsection{Mathematics}
Fubini's theorem states that if a function $f(x, y)$ is continuous on a rectangular region $R = [a, b] \times [c, d]$, then the double integral can be evaluated as an iterated integral:
\begin{equation} \label{eq:fubini}
\iint_R f(x,y) \, dA = \int_a^b \left( \int_c^d f(x,y) \, dy \right) dx = \int_c^d \left( \int_a^b f(x,y) \, dx \right) dy
\end{equation}
